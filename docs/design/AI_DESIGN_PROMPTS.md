# Book Maker AI Design Prompts

## 1. Purpose

This document contains reusable prompts for external AI design tools.

These prompts are based on the Book Maker product brief, IA, and design principles.

They should be used to generate concept directions, not blindly accepted as final design output.

## 2. Master Product Prompt

Use this prompt when you want the AI tool to understand the overall product before generating specific screens.

```text
Design a responsive web product called Book Maker.

It is a quiet, intimate writing product for people who want to someday turn their personal short writing into a book, but keep postponing the start.

The product should help users write short reflective entries, build a private archive of those writings, group them into book drafts, and preview them in a book-like reading experience.

The emotional tone should be warm, literary, calm, reflective, and spacious.

Avoid making it look like:
- a productivity dashboard
- a social media feed
- a generic SaaS landing page
- an enterprise admin tool

Prioritize:
- typography
- whitespace
- reading comfort
- emotional focus
- mobile responsiveness

The product has two main surfaces:
- a public landing page
- a private writing app

The private app is organized around Archive, Drafts, and Write.
```

## 3. Landing Page Prompt

```text
Design a responsive landing page for a product called Book Maker.

Book Maker helps users turn short personal writing into the beginning of a book.

The audience is people who used to write fragments of emotion, memory, and reflection on platforms like Instagram, but never had a proper place to organize those writings into a lasting body of work.

The landing page should feel literary, warm, and emotionally resonant.
It should communicate:
- short writing matters
- scattered writing can become a book
- the product helps users stop postponing their story

Required sections:
- hero section
- problem/insight section
- how it works section
- product preview section
- call to action section

Avoid startup-template visuals, loud gradients, dashboard-style feature blocks, and social-media-like UI patterns.

Make it look intentional, elegant, modern, and editorial.
```

## 4. Archive Screen Prompt

```text
Design a responsive archive screen for Book Maker, a private writing app.

This screen is the user's writing home. It shows accumulated short entries and should feel like a personal literary archive, not a social feed.

The screen should include:
- page title
- quick action to write a new entry
- list of saved entries
- timestamps
- subtle search/filter entry point
- access to drafts

The visual tone should be calm, text-focused, warm, and spacious.

Avoid card-heavy feed aesthetics, engagement UI, and dashboard clutter.
```

## 5. Writing Screen Prompt

```text
Design a responsive writing screen for Book Maker.

This screen is for writing a short personal entry with minimal pressure.

The experience should feel quiet, focused, and emotionally safe.

Include:
- optional title field
- main writing area
- subtle autosave status
- minimal surrounding controls

The interface should make short writing feel valid and complete.

Avoid looking like a blog CMS, document editor toolbar, or enterprise form.
```

## 6. Draft Builder Prompt

```text
Design a responsive draft-building screen for Book Maker.

This screen lets a user group selected writing entries into a book draft and organize their order.

The screen should communicate that the user is shaping a manuscript, not just managing files.

Include:
- draft title
- optional draft description
- selected entries list
- reorder interaction
- add/remove entry controls
- preview action

The tone should still feel literary and focused, but slightly more structured than the archive.

Avoid dense productivity-tool layouts and complicated publishing-software aesthetics.
```

## 7. Draft Preview Prompt

```text
Design a responsive draft preview screen for Book Maker.

This screen should present selected short entries as a continuous reading experience that feels like the beginning of a book.

The user should feel a meaningful emotional shift from editing mode to reading mode.

Include:
- book title
- optional intro text
- entry content displayed in a continuous manuscript-like flow
- restrained navigation back to editing

The design should prioritize readability, whitespace, and editorial atmosphere.

Avoid making it look like a list page or a document management screen.
```

## 8. Mobile Quality Prompt

Use this prompt to ask the AI tool to refine any screen for mobile.

```text
Refine this interface for mobile-first reading and writing use.

Prioritize:
- comfortable thumb interaction
- strong text readability
- spacious but efficient layout
- reduced visual noise
- clear hierarchy on small screens

The experience should still feel literary, calm, and premium.
```

## 9. Evaluation Checklist

After generating designs, evaluate them with these questions:

1. Does this feel like a writing product rather than a dashboard?
2. Does the archive feel like owned writing rather than a feed?
3. Does the writing screen reduce pressure?
4. Does the draft preview feel like reading, not editing?
5. Is the landing page emotionally aligned with the product story?
6. Does the design work on both desktop and mobile?
