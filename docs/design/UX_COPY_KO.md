# 안녕, 나의 바다 한글 UX 카피 가이드

## 1. 목적

이 문서는 `안녕, 나의 바다`의 실제 구현에 사용할 한글 중심 UX 카피 기준을 정리한다.

목적은 다음과 같다.

- 제품 톤을 일관되게 유지한다
- 화면마다 용어가 흔들리지 않게 한다
- 랜딩과 앱의 감정 차이를 분명히 한다
- 실제 Nuxt 구현 시 바로 참고할 수 있게 한다

## 2. 카피 원칙

`안녕, 나의 바다`의 카피는 다음 원칙을 따른다.

- 조용하고 사적인 톤을 유지한다
- 사용자를 몰아붙이지 않는다
- 생산성 도구처럼 차갑지 않게 쓴다
- 지나치게 시적이어서 기능을 흐리지 않게 한다
- 짧지만 여운 있는 표현을 우선한다

피해야 할 톤:

- 과한 스타트업 마케팅 문구
- 과도하게 감상적인 문구
- 기능 설명이 불명확한 추상 표현
- SNS 서비스 같은 가벼운 말투

## 3. 제품명 표기

기본 표기:

- `안녕, 나의 바다`

설명형 보조 표현:

- `글을 쌓아 책으로 만드는 공간`
- `미루던 이야기를 한 권에 가까워지게 하는 곳`
- `만남과 헤어짐 사이에 남는 기록의 공간`

주의:

- 공식 서비스명은 한글 사용
- 영어는 브랜드 해석 문장이나 보조 카피에서만 제한적으로 사용
- 기능/내비게이션/설명은 한글 우선

브랜드 해석 보조 문장 후보:

- `모든 안녕이 머무는 곳`
- `hello와 goodbye, sea와 see 사이의 기록`
- `바다이기도 하고, 보았던 장면이기도 한 기록의 공간`

## 4. 핵심 용어 확정

### 상위 내비게이션

- `Archive` -> `아카이브`
- `Drafts` -> `초안`
- `Write` -> `기록하기`

권장 이유:

- `아카이브`는 단순 목록보다 보관과 축적의 느낌이 있다
- `초안`은 책으로 자라나는 중간 상태를 잘 설명한다
- `기록하기`는 `글쓰기`보다 부담이 적다

### 주요 객체

- `Entry` -> `기록`
- `Draft` -> `초안`
- `Book` -> `책`
- `Preview` -> `미리보기`

### 상태/행동

- `Save` -> `저장`
- `Autosaved` -> `자동 저장됨`
- `Saving` -> `저장 중`
- `Saved just now` -> `방금 저장됨`
- `Add Entry` -> `기록 추가`
- `Remove` -> `제외`
- `Reorder` -> `순서 바꾸기`
- `Create Draft` -> `초안 만들기`
- `Preview Draft` -> `초안 미리보기`

## 5. 랜딩 페이지 카피 초안

### 히어로

헤드라인 후보 1:

- `흩어진 글이 한 권이 되기까지`

헤드라인 후보 2:

- `미루던 이야기를, 한 페이지씩`

헤드라인 후보 3:

- `짧게 남긴 글이 책의 시작이 됩니다`

서브카피 후보:

- `짧은 기록을 쌓아 두세요. 안녕, 나의 바다는 그 조각들이 한 권의 초안으로 자라나는 과정을 보여줍니다.`

브랜드 서브카피 후보:

- `모든 안녕이 머무는 곳`
- `남겨 둔 장면과 마음이 한 권의 흐름이 되는 곳`
- `바다처럼 넓게, 보았던 장면처럼 선명하게`

CTA 후보:

- `기록 시작하기`
- `첫 글 남기기`
- `초안 둘러보기`

### 문제 공감 섹션

제목 후보:

- `글은 남겼지만, 원고는 남지 않았습니다`

본문 후보:

- `SNS에 올린 글은 쉽게 흘러가고, 시간이 지나면 다시 찾기도 어렵습니다. 많이 썼는데도 책은 시작하지 못한 것처럼 느껴지는 이유입니다.`

### 해결 방식 섹션

제목 후보:

- `기록하고, 쌓고, 묶고, 읽어보세요`

설명 문장:

- `부담 없이 짧게 기록하고`
- `아카이브에서 지난 글을 다시 꺼내 보고`
- `서로 닿는 글들을 초안으로 묶고`
- `책처럼 읽히는 화면에서 흐름을 확인합니다`

## 7. 아카이브 화면 카피

### 제목

- `아카이브`

### 설명

- `지금까지 남긴 글을 다시 읽고, 이어 붙일 수 있는 공간입니다.`

### 검색창

플레이스홀더 후보:

- `기록을 찾아보세요`
- `제목이나 문장을 검색해 보세요`

### 빈 상태

제목:

- `아직 남긴 기록이 없습니다`

본문:

- `처음부터 길게 쓰지 않아도 괜찮아요. 오늘 떠오른 장면이나 한 문장부터 남겨 보세요.`

버튼:

- `첫 기록 남기기`

## 8. 기록 작성 화면 카피

### 제목 필드

플레이스홀더:

- `제목은 비워 두어도 괜찮아요`

### 본문 필드

플레이스홀더 후보:

- `오늘 떠오른 장면이나 마음을 남겨 보세요`
- `짧은 문장부터 시작해도 괜찮아요`
- `아직 책이 아니어도 괜찮습니다`

### 하단 상태

- `자동 저장 중`
- `방금 저장됨`
- `이 기록은 나만 볼 수 있습니다`

## 9. 초안 화면 카피

### 제목

- `초안`

### 설명

- `서로 닿는 기록을 모아 책의 흐름을 만들어 보세요`

### 비어 있는 초안 상태

제목:

- `아직 만든 초안이 없습니다`

본문:

- `아카이브에서 기록 몇 개를 골라 초안으로 묶어 보세요. 이미 써 온 글들이 한 권의 시작이 될 수 있습니다.`

버튼:

- `초안 만들기`

### 순서 영역

- `초안 순서`
- `기록 추가`
- `순서 바꾸기`

## 10. 미리보기 화면 카피

### 상단

- `초안 미리보기`
- `수정 화면으로 돌아가기`

### 하단

- `미리보기 끝`
- `다시 다듬기`

설명 문장 후보:

- `이제 글의 흐름을 한 번에 읽어 보세요`
- `목록이 아니라 한 권의 시작처럼 읽히는지 확인해 보세요`

## 11. 인증 화면 카피

### 로그인

- 제목: `다시 이어서 쓰기`
- 설명: `남겨 둔 기록과 초안을 이어서 불러옵니다`
- 버튼: `로그인`

### 회원가입

- 제목: `당신의 글이 머무를 공간을 만드세요`
- 설명: `짧은 기록부터 시작해도 괜찮습니다`
- 버튼: `시작하기`
