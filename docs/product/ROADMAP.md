# Book Maker Product Roadmap

## 1. Purpose

This document organizes all post-MVP feature ideas into phased product development.

The goal is not to reduce ambition.

The goal is to preserve the full product vision while ensuring that features are introduced in the right order.

Book Maker grows through this sequence:

1. private writing
2. archive intelligence
3. book shaping
4. public reading
5. publishing readiness
6. long-term platform expansion

## 2. Phase Overview

### Phase 1. MVP

Goal:

- help users write short entries
- build a personal archive
- create simple book drafts
- experience a book-like preview

Included:

- entry creation
- archive
- draft creation
- draft organization
- draft preview

### Phase 2. Writing Depth And Archive Intelligence

Goal:

- make writing easier to continue
- make archives more meaningful to revisit
- help users discover patterns in their own writing

### Phase 3. Book Structuring And Authoring Support

Goal:

- help users move from a collection of entries to a shaped manuscript

### Phase 4. Public Reading Experience

Goal:

- let users turn private drafts into public reading experiences
- make the product feel like a digital book platform, not only a private writing tool

### Phase 5. Publishing And Export

Goal:

- support real-world output and publication preparation

### Phase 6. Account, Platform, And Collaboration Expansion

Goal:

- make the product reliable across devices and capable of broader usage patterns

### Phase 7. AI Expansion

Goal:

- add intelligent assistance only after the core writing and book-building workflow is proven

## 3. Phase 2. Writing Depth And Archive Intelligence

### 3.1 Creative Support

- writing prompts
- emotion/topic-based writing templates
- serial writing flow
- resurface older writing with similar themes
- continue from today's one sentence
- writing style statistics
- frequently used keyword analysis

### 3.2 Archive Enhancement

- organize by tags, emotion, people, and places
- timeline view
- monthly and yearly reflection views
- group entries by person or theme
- resurface old entries
- find duplicated or similar writing
- collect unfinished writing

### Why This Phase Matters

This phase strengthens the private writing habit and makes the archive feel alive rather than static.

## 4. Phase 3. Book Structuring And Authoring Support

### 4.1 Book Building Features

- chapter creation
- chapter title suggestions
- automatic table of contents draft
- detect awkward flow between sections
- book introduction writing assistant
- author note writing assistant
- cover copy writing assistant
- book title suggestions

### Why This Phase Matters

This phase helps users move from "I have many entries" to "I am shaping an actual manuscript."

## 5. Phase 4. Public Reading Experience

### 5.1 Publish And Read

- visibility settings
- shareable links
- reader comments
- save a sentence instead of generic likes
- bookmarks
- page-turn animation
- read-aloud mode
- dark and light reading mode
- quote and share

### Why This Phase Matters

This phase transforms Book Maker from a private creative tool into a reading experience platform.

It aligns with the long-term vision that a personal draft can become something others can read like a real book online.

## 6. Phase 5. Publishing And Export

### 6.1 Publication Preparation

- EPUB export
- selectable PDF trim size
- separate cover and interior export
- print-shop preset settings
- ISBN and publication metadata management
- versioned manuscript management
- final proofreading checklist
- plagiarism and similarity checks

### Why This Phase Matters

This phase makes the product useful not only for drafting, but also for real publishing preparation.

It is where "my writing may become a book" turns into "my manuscript is ready to become a book."

## 7. Phase 6. Account, Platform, And Collaboration Expansion

### 7.1 Account And Reliability

- cloud sync
- backup and restore
- multi-device sync
- draft version history
- trash and restore

### 7.2 Collaboration And Operations

- co-author support
- invite-based feedback
- admin moderation and operations

### Why This Phase Matters

This phase supports scale, trust, and broader usage beyond a single-user MVP model.

## 8. Phase 7. AI Expansion

### 8.1 Intelligent Assistance

- book structure suggestions
- title recommendations
- sentence refinement suggestions
- summary generation
- chapter mood analysis
- reader-facing book recommendations

### Why This Phase Matters

AI should strengthen the user's writing process, not replace it.

This phase is intentionally later because Book Maker must first prove that its core archive-to-book workflow is valuable on its own.

## 10. Priority Logic

The roadmap follows these principles:

1. private writing comes before public reading
2. archive intelligence comes before AI
3. book shaping comes before publishing export
4. proven user value comes before platform complexity

## 11. What This Means Strategically

Book Maker is not only a note app and not only a publishing tool.

It evolves in layers:

- first as a private writing system
- then as a manuscript shaping tool
- then as a digital reading and publishing platform
