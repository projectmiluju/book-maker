# Book Maker Product Brief

## 1. Product Summary

Book Maker is a writing product for people who want to someday turn their personal writing into a book, but keep postponing the start.

The core idea is simple:

Short pieces of writing should not disappear like social posts. They should accumulate as material that can later become a book draft.

## 2. Target User

The primary persona is a general user who wants to someday compile their writing into a book.

This user:

- is not necessarily a professional writer
- often writes short emotional or reflective texts
- has experience posting writing on Instagram or similar platforms
- wants their writing to feel personal, but also relatable to others
- struggles to organize past writing into a usable manuscript archive

## 3. Problem Statement

Users can write short texts consistently, but those texts are often trapped inside SNS feeds.

This creates several problems:

- writing is easy, but retrieval is difficult
- past posts are not structured like an archive
- accumulated writing does not naturally become a manuscript
- the user feels like they have written a lot, but still have not "started a book"

## 4. Core Value Proposition

Book Maker helps users move from:

- scattered short-form writing
- to organized personal archives
- to a book draft experience

The product should make the user feel:

"I was not failing to write a book. I was already writing one."

## 5. Product Principles

- Do not force long-form writing from the beginning.
- Reduce the pressure of a blank page.
- Treat short writing as meaningful creative assets.
- Make accumulation visible.
- Show the user that their writing is turning into a book.

## 6. MVP Goal

The MVP should help users:

1. quickly write short entries
2. revisit and organize accumulated entries
3. group selected entries into a simple book draft

The first success metric is not publishing a book.

The first success metric is:

The user writes several short entries, sees them gathered as a draft, and wants to keep going.

## 7. MVP Features

### 7.1 Quick Writing

The user should be able to save a short piece of writing with minimal friction.

Minimum requirements:

- write immediately without heavy setup
- optional title
- body text
- automatic created date

### 7.2 Archive

The user should be able to revisit past writing as a personal archive.

Minimum requirements:

- list of entries
- chronological ordering
- preview of each entry
- simple search or filtering

### 7.3 Book Draft Builder

The user should be able to select entries and turn them into a simple book draft.

Minimum requirements:

- select multiple entries
- define a draft title
- arrange entry order
- preview them as a continuous reading experience

## 8. MVP User Flow

1. User writes a short text.
2. The text is saved as an entry.
3. More entries accumulate over time.
4. The user revisits old writing.
5. The user selects several entries.
6. The product groups them into a draft.
7. The user sees a book-like preview and feels motivated to continue writing.

## 9. Out of Scope

The following should not be included in the first MVP:

- social publishing
- collaboration
- advanced formatting tools
- AI ghostwriting
- print ordering
- payment and subscription systems
- highly automated chapter generation

## 10. Working Product Thesis

The product is not just a memo app.

It is not a full publishing tool either.

It should sit in the middle:

- as easy to write into as SNS
- as structured as a personal archive
- as motivating as a book draft tool
