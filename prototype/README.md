# Book Maker Prototype

This folder contains a static design prototype derived from the Stitch directions, but simplified to fit the confirmed MVP.

Included screens:

- `index.html`
- `archive.html`
- `write.html`
- `draft-builder.html`
- `draft-preview.html`

Principles applied:

- public landing and private app are visually separated
- writing view is simplified for low-pressure entry
- draft builder is lighter and less tool-like than the original Stitch draft
- preview is focused on reading, not controls

To view locally, open any file in a browser.
